# Home Screen Icon Credits

Images on the home screen's game tiles. Every one is original art generated in-house; they use no
third-party art. `src/__tests__/assetCredits.test.ts` fails if a file here has no row, and
`src/__tests__/lobbyTileBudget.test.ts` caps each tile at 3,400 B.

| File                | Pack                                                       | Source file              | Notes                                                                                                                                                                         |
| ------------------- | ---------------------------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| starswarm-tile.webp | Original, generated by tools/assets/draw_starswarm_art.py  | recipe `home-tile-badge` | The Star Swarm tile icon: the Wasp Grunt in a silver-bevelled hex badge, 168 px (#3599, #3708).                                                                               |
| sort-tile.webp      | Original, generated by tools/assets/draw_lobby_tile_art.py | scene `sort`             | Sort Puzzle: a lifted flask pouring pink into the middle of two upright flasks, 192 px (#4004, #4011).                                                                        |
| yacht-tile.webp     | Original, generated by tools/assets/draw_lobby_tile_art.py | scene `yacht`            | Yacht: all five dice, four landed on fives and the fifth tumbling in, 192 px (#4011).                                                                                         |
| twenty48-tile.webp  | Original, generated by tools/assets/draw_lobby_tile_art.py | scene `twenty48`         | 2048: two 1024 tiles sliding together on a slice of the board, 192 px (#4011). Numerals are Space Grotesk Bold outlines (SIL OFL 1.1, `tools/assets/lobby_numerals.OFL.txt`). |
